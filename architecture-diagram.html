EU Sports Mapping Tool — Architecture & Data Flow

League & Team Mapping Console (BCM · Betradar · Betgenius) · Owner: Siva Kumar Batte
⚠ Prototype / Test environment — prepared for security assessment

The tool is a browser-only web application with no server-side code of its own. The agent's browser loads static web files and then talks directly to a hosted database service (Supabase) over HTTPS. There are three layers: the browser, the database's REST API, and the database itself.

Tables (6)

Data stored: only Basketball & Ice Hockey league/team names and the items above.

⚠ users table stores passwords in plaintext

Step-by-step: what happens when an agent uses the tool

  1. The agent opens the tool's web address; the browser downloads the static files (index.html etc.) from the host.
  2. The agent enters a username and password. The browser sends this to the Supabase REST API and checks it against the users table.
  3. On success, the app loads the mapping data by requesting rows from the leagues and teams tables over HTTPS.
  4. When the agent adds, edits, bulk-uploads, or deletes a mapping, the browser sends a POST / PATCH / DELETE request to the REST API, which writes to the database.
  5. Every change is also written to the history table as an audit record (who, what, when).
  6. For the LBC / DataFeed tools, Excel files are read inside the browser (using the CDN library) — the file itself is not uploaded to the database.

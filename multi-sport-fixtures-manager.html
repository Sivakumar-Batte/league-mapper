Manage Basketball, Ice hockey, Floorball, Waterpolo, Bandy, and Field hockey priority leagues, paste Flashscore fixtures, filter matches, keep a seven-date collection, and compare it against worked matches. Everything is stored in this browser.

1. Priority League Mappings 0 mappingsClick to manage mappings ▾
Each sport has its own independent mapping table. Import a CSV, tab-separated file, or Markdown table with columns Country, Priority League, Flashscore League Name and (optionally) Sport and Active. If the file has no Sport column, every row is assigned to the sport chosen in the form below. Excel (.xlsx) files should first be saved as CSV UTF-8. Blank Flashscore names are kept in the list but never match fixtures. Inactive mappings are never used for matching. A country-specific mapping only matches fixtures from that country; a broad-region mapping (Europe, Asia, Africa, America, Oceania, World) only matches fixtures labelled with the same region family.
Shared list: on start-up the app loads the team's mapping list from the Supabase table msfm_priority_mappings (read-only). Edits made here are saved in this browser only; to share a change, update it in Supabase (use Export Mappings as Supabase SQL).

Paste Excel rows: Sport, Date, Time, Country, League, Home, Away, Event ID

Copy the 8 columns from Sport Name through Event ID in Excel and paste them below. Collected priority fixtures are compared with the worked history by sport, date, country, league, home/away teams and time. An Event ID never overrides conflicting details, similar team names are sent to review rather than accepted silently, and the same teams found on the adjacent date (midnight / time-zone shifts) are also sent to review.
